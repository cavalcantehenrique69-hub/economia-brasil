# Projeto de Economia

## Sobre o projeto

O objetivo é apresentar informações relacionadas à economia por meio de diferentes páginas HTML, utilizando links para permitir a navegação entre elas.

O projeto foi desenvolvido como uma atividade prática para aplicar conhecimentos básicos de desenvolvimento web.

## Tecnologias utilizadas

* HTML

O projeto utiliza somente HTML para a criação e organização das páginas.

## Páginas do projeto

O projeto é dividido nas seguintes páginas:

* **Início** — Página principal do projeto, responsável por apresentar o conteúdo inicial e direcionar o usuário para as demais páginas.
* **PIB e Inflação** — Página com informações sobre o Produto Interno Bruto (PIB) e a inflação.
* **Mercado de Trabalho** — Página com informações relacionadas ao mercado de trabalho.
* **Câmbio e Comércio Exterior** — Página com informações sobre câmbio e comércio exterior.

## Navegação

As páginas possuem links que permitem ao usuário navegar entre os diferentes conteúdos do projeto.

A navegação pode ser realizada de diferentes formas, permitindo que o usuário acesse as páginas sem precisar seguir uma ordem específica.

## Objetivo

O principal objetivo deste projeto é praticar os conceitos básicos de **HTML**, principalmente:

* Criação de páginas HTML;
* Utilização de links;
* Navegação entre páginas;
* Organização de conteúdo;
* Estruturação de um pequeno site.

## Desenvolvimento

O projeto foi desenvolvido utilizando o **Visual Studio Code**, utilizando apenas HTML para a criação das páginas.
